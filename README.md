# Lista_de_tarefas  
Projeto 4- Lista de tarefas em Python    

Esse projeto simples em Python contém:

# to_do_list.py
- Importa a biblioteca json e a biblioteca os  
- Cria o arquivo tarefas.json  
- Funções:  
  Carregar tarefas  
  Salvar tarefas  
  Adicionar tarefas(prioridades: Alta, Média ou Baixa, lista as tarefas: descrição, conclusão e prioridade)
  Listar tarefas  
  Remover tarefas  
  Editar tarefas

  # Arquivo Principal(Main.py)  
  - Importa to_do_list.py  
  - Um laço com as opcoes adicionar tarefa, listar tarefa, remover tarefa, editar tarefa e sair do sistema
